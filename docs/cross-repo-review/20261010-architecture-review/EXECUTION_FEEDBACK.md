## 四、ST unit 与 Gene 两维 uncertainty

用户已明确将两维 uncertainty 融入重建，并用于下游置信度；此方向纳入后续方法设计，暂不以旧实验指标代替新定义。

实施前明确：每个量针对原始测量、表达预测、类型映射或位置中的哪个对象；其轴、单位、含义、校准与消费者是什么。

建议：

1. **保留两轴汇总，支持局部条件查询。** 某 gene 的全局可靠性与某 unit 的整体可靠性，不足以证明它在该 unit/区域一定可靠。按需查询局部 gene×unit 可信度，不预先要求存储全量大矩阵，也不直接把两分数相乘当概率。
2. **区分估计对象。** 类型映射、表达预测与空间位置可靠性分别解释；坐标继承而非重建的路线，需要说明坐标/归属支持，不能伪造位置重建后验。
3. **区分生物变异与技术不确定性。** 表达异质性、低空间平滑本身不能直接当作噪声，避免压制真实罕见状态。
4. **贯穿下游。** Gene/DEG 消费当前比较的不确定性；Pathway 结合基因覆盖、贡献与相关误差；CCI 结合 ligand/receptor、细胞身份及邻域支持；区域解释保留空间归属可靠性。
5. **校准优先利用适当的 case 对照。** 核查更高置信度是否对应更小实际误差，区间是否满足声明的覆盖；不把未经校准的 score 称为正确概率。具体校准设计随方法与现有证据决定。

已有实现边界：`gene_uncertainty.py` 使用 reference 表达 PCA/kNN 图，输出 gene-wise Moran/Geary 与表达分布统计，是实验性结构稳定性线索；`Confidence` 为类别 posterior 最大值，没有完成校准；当前坐标检查只验证合法性与对应一致。上述量不能改名后直接声称完成新两维 uncertainty 方案。
