## 1. 要开发什么、首批怎样验收

开发能读取生信证据、检查前提、调用适用分析、组织生物学故事并提出/检验候选解释的 Agent。近期用 Fig6/7 的 T、TAM、CAF 生信 case 作为首批参考与回归对象，系统覆盖 ST unit/亚型、Gene、Pathway、CCI、具体空间区域。重点为 Fig6 C–J、M–N 与 Fig7 A–E、G 的生信内容；临床/IFA/谱系 panel 不进入当前分析管线。

首批成果是几类亚型与关键基因的完整故事：分子变化、功能程序、通讯候选和空间情境连接清楚，关键陈述能回到实际生信结果，通过适用的计算检查使生物学假设基本确立，能区分观察、解释与假设。后续临床、IFA、谱系与外部队列属于体系外验证，可与假设关联，不纳入当前数据管线、payload、Agent工具或完成门槛；不要求这些验证或全套 uncertainty 算法完成后才开发。

ST unit 与 gene 两维 uncertainty 将融入重建与下游可信度，这是后续方法方向。当前没有的估计量明确不可用；不要把类别 Confidence 或 gene 图统计改名为已校准的表达/位置置信度。

复用现有 index/result、正式报告导出与运行记录。历史结果可用明确的来源登记导入；不要求为整理而重算全部分析，也不要求每个阅读槽位成为独立计算 analysis。

| 材料 | 必须让接手者知道什么 |
| --- | --- |
| 固定代码与环境 | 两仓 commit/branch、实际运行 checkout、解释器/依赖、哪些接口可运行 |
| 数据/结果入口 | 原始输入或历史结果在哪里、hash、生成 run/方法、表达来源、参数、获取/访问方式 |
| 标签与范围 | 该输入的 cluster→paper-facing 标签映射及依据；不同重跑不得仅按数字认定同类 |
| 五层覆盖 | 声明 universe、实际评估实体、结果定位、不可比/未评估/失败原因；焦点结果可以是 partial |
| 证据定位 | 表名与行/键、图或 notebook cell、统计列的真实含义；来源侧与对象匹配 |
| 科学解释 | 生信计算观测、支持的解释与生物学假设分别说明；保留替代解释与下一可检验问题。后期验证只保留关联，不作为当前事实层 |

`summary.json`、payload、README、HTML 从同一组登记结果派生。三槽位只提供阅读视图。缺值不补零，不把模型推断写成原位实测，不把论文陈述写为本次新计算结果。

原始 H5AD/结果未必由 Git 纳管。合作方需要同时取得小型证据快照及数据/远程执行入口；仅 clone 代码或收到 report.html 不构成完整科学开发交付。共享 qz 权限或离线交付方式由用户与合作方实际安排，不在本说明中假定已具备。

## 5. Agent 的首批工作流

1. 读取样本身份、覆盖与状态，选择可回答的问题。
2. 从亚型/故事或空间区域入口检索 Gene、Pathway、CCI 和区域证据；按实际问题下钻，不能只读载荷的全局 head(6)。
3. 检查对象、输入侧、方法、分母及比较条件。数据不足时说明缺口；需要计算时调用适用现有分析、对照或稳健性检查，写入独立输出范围，保护输入和已有结果。
4. 组织“生信观察→程序与空间解释→生物学假设→计算支持/限制→下一问题”；不预定只能得到 H1–H4。可以提出后期验证命题，不负责整合或执行临床/IFA/谱系验证。
5. 验证关键数字和解释是否有直接来源，记录支持与不支持的证据。Fig6/7 用于 case 参考/验收；复述已给定结论本身不证明独立发现能力。

故事输出格式由合作方实现，不强加新框架；至少包含问题、亚型/基因/区域、生信证据引用、解释层级、计算检查、替代解释、需要的下一检验与当前状态。无需加入后期验证数据模型。

## 6. 首批验收检查

| 检查 | 达标表现 |
| --- | --- |
| 系统化覆盖 | 五层均有可读结果或明确缺口；空间情境贯穿，实际 focal scope 与 universe 分开 |
| 三类 case 故事 | T 的增殖/TRM/Treg、T–TAM 情境及通讯候选、CAF 程序与来源均能形成有证据的故事；无需每个故事都有全部层面显著结果 |
| 数字核验 | 关键 DEG、通路和 LR 数字能定位正确来源行；p=1 不称显著，score 不挪到另一 cell-pair，ORA 不称 GSEA |
| 科学假设范围 | 生信支持什么就陈述什么；调节生态位、代谢耦合及侵袭分工按实际证据组织假设；CAF8称ECM-breakdown。后期临床/IFA/谱系不用于为当前推断直接贴“机制已证”标签，也不要求纳入当前验收 |
| 缺失/反证 | 对不支持、不可比或不可用条目如实说明，并能调整/撤回候选解释 |
| 按需探索 | 能调用一个适用的已有分析或明确指出所需缺失条件，保留参数/状态/来源；不限于静态载荷总结 |
| 交付一致性 | 快照 hash 可检查，引用可解析，摘要与底表一致；声明实际部署版本 |
